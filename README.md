# Spring Hotel

Курсовая работа по информационной безопасности «Разработка защищенной базы данных для управления гостиницей». В рамках проекта я спроектировал базу данных MySQL и реализовал CRUD-веб-приложение для управления гостиницей.

## Документация

- В разделе «Описание методов защиты приложения» разобраны резервное копирование MySQL, шифрование, защита от SQL-инъекций, аутентификация и авторизация. [Отчёт по курсовой работе, стр. 58–75](docs/KP_hotel_Spring.pdf#page=58)
- Маршруты, формы и правила доступа для менеджера, администратора и службы гостиничного хозяйства. [Документация HTTP-интерфейса](docs/api.md) · [Матрица ролей](docs/api.md#матрица-ролей)

## Безопасность

- Сотрудники входят через форму и работают в сессии. Для проверки паролей используется BCrypt. Учётные записи заданы в памяти приложения.
- Spring Security разграничивает права менеджера, администратора и службы гостиничного хозяйства. Менеджер работает с клиентами, договорами и бронированиями. Раздел персонала доступен менеджеру и администратору, а страница журнала уборки и техосмотров — всем трём ролям.
- Для операций с MySQL используются репозитории Spring Data JPA. Hibernate передаёт значения полей в SQL через параметры запросов.
- В текущей конфигурации CSRF отключён. [Настройки Spring Security](src/main/java/com/project/hotel/config/SecurityConfiguration.java)

## Возможности

- Управление бронированиями, данными клиентов, договорами и счетами.
- Просмотр и добавление сотрудников уборки и техперсонала, просмотр страницы журнала уборки и техосмотров.
- Управление каталогом дополнительных услуг.

## Технологии

Java 17, Spring Boot, Spring MVC, Spring Security, Spring Data JPA, Hibernate, Thymeleaf, MySQL и Lombok.
